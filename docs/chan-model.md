# 缠论结构模型与执行边界

3.3.0 使用顺序输入的已收盘日 K。结构极值所在日期与实际确认日期分别记录；回测在确认后才产生委托，不把后来的结构回填到早先的最低价。

## 结构层

包含处理按走势方向归并高低点。分型要求中间标准 K 的高、低同时高于或低于两侧；严格笔保留两个分型之间的独立 K。末笔可延伸，历史信号保存当时的观察结果。

交易中枢仍是三根锁定笔的重叠代理，有固定边界和生命周期。原书的中枢定义涉及已完成的次级别走势类型；时间周期、笔、线段及走势级别不能直接等同。线段诊断仅实现标准特征序列的无缺口子集；遇到缺口需反向特征序列确认时明确待定，停止继续划分，不把任意三笔拼成线段。这些线段诊断不参与交易，也不等于已经实现所有递归级别。

三买、三卖识别离开中枢后的首次有效回试。二买包含一买之后首次回试及明确标注的转强首次回试子集。趋势背驰需要独立中枢、可比走势与 MACD 力度证据；盘整背驰单独标注，不能只凭指标缩短推导趋势一买。

界面提供三买、二三买、一二三买模式；所有条件和结构层级都在信号说明中公开，不将 CAN SLIM、均线、持仓比例或追涨幅度混成缠论定义。

## 交易层

已有持仓不会阻止新买点，也不会阻止手动再下单。每股固定下单数量由用户配置；信号产生、下单数量、资金冻结、委托成交、持仓退出分别处理。

同股最多三笔活动委托。自动模式按确认事件记录派发状态，防止刷新或重启反复提交；手动可以重新提交。委托没有次日自动过期或价格跳空阈值。基础资金、申报数量、交易时段、行情时效及可卖量仍校验；结构止损用于退出，不用于禁止买入。

原书第26课在既定配置内讨论卖点减量、买点回补；第49课讨论中枢震荡中的增减量；第94课要求加减仓有完整计划。不能从作者某种资金管理方式推导出软件必须“先清仓才能再次买入”。

## 可复现验证

自动测试覆盖分型右侧确认、包含链、笔延伸、首次回试、中心替换、结构背驰、追加历史不修改已发事件，以及信号和成交时刻分离。研究回测显示未成交原因；增加信号或放宽执行限制不能单独证明收益提高。

相关模型源码是 `chan_strategy.py`；执行与回测源码分别为 `local_strategy_runtime.py`、`local_strategy_panel.py` 和 `strategy_backtest.py`。本模型无需行情平台账号或外部 AI。
